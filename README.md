# 小羊毛

小羊毛是一个手机优先的个人优惠入口导航，首版包含外卖闪购、网购省钱和出行优惠三个分类，并支持作为 PWA 添加到手机桌面。

## 添加真实优惠链接

所有平台配置集中在 `platforms.js`。找到对应平台，将 `href: null` 替换为完整的 HTTPS 地址即可，例如：

```js
href: "https://example.com/coupon",
```

只有无账号密码的绝对 HTTPS 地址会被启用；其他值仍会显示为“待添加链接”。若以后加入推广或返佣链接，请同时在页面中增加清晰披露。

## 本地使用

- `npm run dev`：在 `http://127.0.0.1:4173/` 预览。
- `npm run build`：生成 Sites 可部署输出。
- `npm test`：构建并检查平台配置、链接安全和 PWA 资源。
